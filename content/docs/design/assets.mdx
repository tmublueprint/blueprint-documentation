## Design System

### Colors

| Name | Hex | Usage |
|------|-----|-------|
| Primary | `#0070F3` | Buttons, links |
| Secondary | `#5C7CFA` | Secondary actions |
| Background | `#FFFFFF` | Page background |
| Text | `#1A1A1A` | Body text |

### Typography

- **Headings**: Inter, Bold
- **Body**: Inter, Regular
- **Code**: JetBrains Mono

## Mockups

Store design files in `/public/design/`:

- `figma-export/` - Exported Figma components
- `wireframes/` - Low-fidelity wireframes
- `mockups/` - High-fidelity mockups

## Guidelines

1. Follow the existing design system
2. Use provided components when possible
3. Document any new patterns added
